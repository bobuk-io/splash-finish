# Splash Finish 0.3.19

- **Agterm sessions without `--source-url`:** in a local Agterm session (`AGTERM_ENABLED=1` and a full `AGTERM_SESSION_ID`), `notify` and the installed hooks capture the `agterm://session/<UUID>` link themselves, so clicking a notification returns to that session. An explicit `--source-url` still takes precedence; the link selects the session, not a split pane. Contributed by Gregory Nickonov (#8).
- **Homebrew updates and `brew trust`:** Homebrew now loads casks from taps other than its own only after you trust them. When an update fails with "Refusing to load cask bobuk-io/tap/splash-finish from untrusted tap", the **Update Splash Finish via Homebrew…** window explains it and offers **Trust and Update**, which runs `brew trust --cask bobuk-io/tap/splash-finish` only when you click it, then updates. If your copy cannot reach 0.3.19 for this reason, run `brew trust bobuk-io/tap` once, then `brew upgrade --cask bobuk-io/tap/splash-finish`.
- **Fresh releases are found:** Homebrew updates refresh the taps first, and the cask no longer says `auto_updates`, so a plain `brew upgrade` includes Splash Finish.

Your inbox, settings, and existing integrations are retained. Homebrew copies update with **Update Splash Finish via Homebrew…**; standalone copies update with **Check for Updates…**.
