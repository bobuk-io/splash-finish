# Splash Finish 0.3.18

- **Oh My Pi (OMP) integration:** install or update from **Integrations** or with `splash-finish install-skills --agent omp` (and inspect with `splash-finish doctor` or remove with `uninstall-skills --agent omp`). Notifies from the main interactive terminal session when turns settle — waiting for background async jobs and queued messages — or when OMP needs attention for `ask`, tool approvals, or plan reviews, without copying prompts, answers, or transcripts into the inbox. Honors `PI_CONFIG_DIR`, `OMP_PROFILE` / `PI_PROFILE`, `PI_CODING_AGENT_DIR`, and `SPLASH_FINISH_DISABLED=1`, and prevents conflicting installs when pi and OMP point to the same agent directory.
- **Agterm session links:** `agterm://` is now allowed in `--source-url` (for example `--source-url "agterm://session/$AGTERM_SESSION_ID"`), so clicking a notification can return directly to the originating Agterm session.

Your inbox, settings, and existing integrations are retained. Homebrew copies update with **Update Splash Finish via Homebrew…**; standalone copies update with **Check for Updates…**.
